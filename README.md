## 🚀 About The Project

A production-grade, dual-application portfolio ecosystem consisting of:
- **Client Portfolio**: A fast, responsive developer showcase with an interactive project gallery, skills matrix, recruiter contact channel, and a print-ready ATS resume generator.
- **Admin Operation Hub**: A secure, authenticated Content Management System (CMS) enabling real-time content management, Supabase Cloud Storage asset uploads, and an inbound recruiter message inbox.

### 🛠️ Tech Stack
- **Frontend**: React 19, Vite 8, Tailwind CSS v4
- **Backend & Auth**: Supabase (PostgreSQL, Storage, RLS, Auth)
- **Deployment**: Vercel (SPA rewrites, security response headers)
